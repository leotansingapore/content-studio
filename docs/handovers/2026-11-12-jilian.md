## Working rules in this repo

Read CLAUDE.md first. A push to main is the deploy, so never run `vercel --prod`. Several sessions push to this repo, including Leo's, so fetch and rebase right before every push, and say in the team chat when you start on StudioLayout.tsx or src/lib/nav.ts, since two sessions rewrote those files at once today. Work in a worktree off origin/main with one logical change per commit, written as `feat:`, `fix:` or `improve:` plus what a user would notice, and run `npm run build` and the full `npx vitest run` before every push. Several pages pin their first frame in `src/pages/__pins__`; regenerate a pin only when the change was on purpose, and diff it first. Icons come from `@phosphor-icons/react` with names ending in Icon (lucide-react is gone, and its import will fail the build). Saved data uses the `content-studio-` key prefix, every view gets a URL (docs/deep-links.md), and edge functions deploy with `supabase functions deploy <name> --project-ref hgdbflprrficdoyxmdxe --use-api`. On localhost, sign in as user@demo.com / demo123456 and add `?asLeo=1` once to see Leo-only pages.
